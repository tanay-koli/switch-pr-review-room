# Feedback on Switch

## What I like about Switch

- Agents feel like teammates in a chat room.
- @mention hand-offs need no extra code and keep the whole history in one thread.
- Mattermost comes built in, so there are no bot tokens or admin rights to set up.
- Each agent can use its own model.
- The activity view shows exactly what each agent ran.
- Humans stay in control, with approval required before merging.

## What I'd improve

- Clearer Windows setup when OpenCode isn't found on PATH.
- A warning when an agent finishes without posting a reply.
- Every agent's working directory shown in one place, with mismatches flagged.
- Session status: whether it's thinking, waiting for permission or stuck, with an optional timeout.
- Export and import whole rooms as templates.
- Invite or edit agents in bulk.
