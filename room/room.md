# Room

**Chat app:** Mattermost (bundled with a local Switch server)

**Name:** `pr-review-room`

**Description:**
```
Where people and AI agents review pull requests together. @reviewer checks the code, @tester runs the tests, @release prepares the changelog, and a human approves every merge.
```

**Members:** you (the lead) plus all nine agents: `planner`, `builder`, `reviewer`, `tester`, `release`, `summary`, `security`, `docs`, `test-writer`.

Add any agent that is missing with `/invite @<agent-name>`.
